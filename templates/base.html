About SpamGuard AI

A student-friendly project that classifies SMS, email and text messages as spam or legitimate using a locally trained machine learning model. No paid APIs are used.

Technologies

Flask · scikit-learn (TF-IDF, Naive Bayes, Logistic Regression) · NLTK · MySQL + SQLAlchemy · Bootstrap 5 · Chart.js
